# おばけの住処

**現在のバージョン：v0.2.0**

かどかとまるが、薄暗い洞窟の中をただのんびり漂う小さな pygame ゲームです。

2匹はそれぞれ別々に、「立ち止まる」「6〜8秒ほどかけて大きく宙返りする」「現在の前方へまっすぐ進む」「現在の前方へ短時間だけ速く進む」「360度の中から新しい進路を選ぶ」「相手へ近づいて話しかける」から行動を選びます。話しかける側だけが相手へ移動し、近づいてから2匹が止まって会話します。水場の近くにいるときだけ「水場で休む」も候補に加わります。壁まで来ると振り返って前向きに進みます。戦闘・スコア・ゲームオーバーはありません。

画面内を左クリックすると、2匹は現在の行動を中断してクリック地点へ寄ってきます。到着後は通常の自由行動へ戻ります。

移動中は約3〜6秒で一往復する、ゆっくりした上下の浮遊揺れが重なります。

自由行動では横長の画面に合わせ、上下移動よりも左右方向へ大きく移動する進路を選びやすくなっています。左右端そのものを目的地にするのではなく、左右どちらもランダムに選びます。上下を含む360度の進路も残されています。

## いちばん簡単な起動方法（Windows）

1. このフォルダーにある `run_game.bat` をダブルクリックします。
2. 初回だけ、専用環境の作成と pygame のインストールが行われます。
3. `F11` または `Alt + Enter` で全画面表示を切り替えられます。
4. ゲームを閉じるときは、ウィンドウを閉じるか `Esc` キーを押します。

Python 3.10 以上が必要です。インターネット接続が必要なのは、pygame が未導入の初回起動時だけです。

ベータ版の変更内容は `CHANGELOG.md`、公開時の説明文は `RELEASE_NOTES.md`、利用条件は `LICENSE.md` を参照してください。

## コマンドで起動する場合

```powershell
py -m pip install -r requirements.txt
py game.py
```

最初から全画面で起動する場合は `py game.py --fullscreen` を使います。

`py` が使えない環境では、代わりに `python` を使ってください。

## 内容

- `game.py` — ゲーム本体
- `characters.json` — 画像・表示名・開始位置・大きさ・移動傾向などのキャラクター定義
- `character_editor.py` — キャラクター定義を編集するエディター
- `assets/kadoka.png` — 1152×1152・背景透過済みのかどか
- `assets/maru.png` — 1152×1152・背景透過済みのまる
- `assets/game_device.png` — 背景透過済みの小さなゲーム機
- `assets/editor_cave_preview.png` — オブジェクト配置用の住処プレビュー
- `requirements.txt` — 必要なPythonパッケージ
- `run_game.bat` — Windows用のかんたん起動ファイル
- `conversations.json` — 編集可能な会話デッキ
- `conversation_editor.py` — 会話エディタ本体
- `run_editor.bat` — ゲームとは別に会話エディタを起動
- `object_editor.py` — ドット絵の作成・保存・配置を行うオブジェクトエディター
- `run_object_editor.bat` — オブジェクトエディターの起動ファイル
- `run_engine.bat` — ゲームと各エディターをまとめて開く統合エンジン
- `engine_project.json` — エンジンが読むプロジェクト定義
- `placed_objects.json` — 住処に置いたオブジェクトの位置と表示サイズ
- `objects` — 作成した1024×1024透過PNGと再編集用データの保存先

## オブジェクトを作って住処に置く

`run_object_editor.bat` をダブルクリックします。初回だけ必要な画像処理部品が自動で準備されます。

1. 16×16、32×32、64×64、128×128からキャンバスを選びます。編集表示倍率は50〜400%で変更でき、Ctrl＋マウスホイールでも拡大・縮小できます。128×128では自動的に200%へ拡大されます。
2. 「色を選ぶ」で描画色を決めます。透明消しゴム、右クリック、または「背景を全部透明」で透明部分を作れます。
3. 名前を付けて保存すると、画面上の大きさに関係なく常に1024×1024の透過PNGになります。
4. 右側の住処をクリックして中心位置を選び、「ゲーム内の幅」で大きさを調整します。縦横比は自動で維持されます。
5. 「新しく住処に置く」を押し、ゲームを起動し直すと反映されます。

住処に置いたものは一覧またはプレビュー上で直接選択できます。プレビュー上でドラッグすると移動し、「住処から外す」で削除できます。保存済み一覧から同じ画像を何度でも挿入でき、配置済みの湧き水・大小の岩・灰色の拾い物も最初から保存済みオブジェクトになっています。

配置には会話用タグを1つ設定できます。タグは配置ごとに重複しない名前にしてください。最初からあるオブジェクトには `water`、`small_rock`、`large_rock`、`found_item`、`game_device` が設定されています。ゲーム機は開始時には非表示で、ゲーム機イベントの途中でまるが取り出します。会話エディタでは、これらのタグを使っておばけを対象へ移動させたり、対象を取り出して表示したり、しまって非表示にしたりできます。

元のキャンバス情報もPNGと一緒に保存されるため、「編集キャンバスへ読み込む」で元のマス目から再編集できます。編集表示の拡大率は保存画像に影響しません。ゲームでは1024pxの画像から滑らかに縮小するので、表示サイズを大きくしても低解像度画像を直接引き伸ばしません。

## 会話を編集する

`run_editor.bat` をダブルクリックすると、会話エディタだけが起動します。会話の追加・削除・並べ替え・セリフ編集を行い、「JSONへ保存」を押してください。通常会話のほか、会話後に水場へ移動する「水浴び」と、ゲーム機を見つけてまるが逃げる「ゲーム機イベント」を選択できます。保存内容は次回ゲーム起動時から反映されます。

ひとつの会話には手順を何個でも追加できます。「セリフ」「タグへ移動」「タグの物を取り出す」「タグの物をしまう」を好きな順番に並べ、話すおばけまたは動くおばけを選びます。取り出したオブジェクトは選んだおばけのそばに表示され、しまうと画面から隠れます。水浴びとゲーム機イベントは会話を終了するイベントなので、手順の最後に置いてください。

会話デッキの各項目には1〜999の「発生の重み」を設定できます。たとえば重み1と重み9の会話がある場合、重み9の会話は重み1より約9倍選ばれやすくなります。水浴びとゲーム機イベントも通常の手順として「手順の種類」でイベントを選んで追加します。ゲーム機イベントでは `game_device` タグのゲーム機をまるが取り出します。

会話を始めるときは片方だけが相手へ近づきます。相手は話しかけられる直前まで自由行動を続け、会話が始まると2匹が向き合います。「水浴び」では会話後に2匹が水場へ移動します。「ゲーム機イベント」ではまるがゲーム機を取り出し、光ったあとに2匹が左右反対の画面端へ高速で逃げます。

洞窟の地形とほこりの粒はゲーム内で描画しています。岩・拾い物・地下水はオブジェクトエディターで編集できる配置画像です。住処の内部解像度は 960 × 540 ピクセル（16:9）です。

## 統合エンジンを開く

`run_engine.bat` をダブルクリックすると、ゲーム、キャラクターエディター、会話・イベントエディター、オブジェクト・部屋エディターを1つの画面から起動できます。統合画面は `engine_project.json` を読み込むため、今後は同じエンジン層から別のゲームプロジェクトも扱えるように拡張します。

キャラクターエディターでは、かどかとまるの表示名、画像、開始位置、表示身長、行動速度倍率、元画像の向き、吹き出しの高さを編集できます。「characters.jsonへ保存」後、ゲームを起動し直すと変更が反映されます。IDは会話・イベントとの接続に使うため、この画面では変更できません。
