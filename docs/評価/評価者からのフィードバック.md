# 評価フィードバック

評価フィードバックの正本は GitHub Issues です。
https://github.com/tomiya7688/obake-no-sumika/issues

## 運用

- 評価者は、確認した内容・再現手順・期待する結果を Issue に記載する。
- 既存 Issue と重複しないか確認してから登録する。
- 実装者は対応する Pull Request から Issue を参照し、確認後に Close する。

2026-09-06 の Grok 評価は、主に [#2 観察ゲームとしての体験密度を高める](https://github.com/tomiya7688/obake-no-sumika/issues/2) と [#4 ゲーム・エンジン・UI・データの責務を分離する](https://github.com/tomiya7688/obake-no-sumika/issues/4) に移行済みです。
