# 評価ログ 機能説明書

## 目的

開発中に、かどか・まる・配置オブジェクトの座標や状態をJSONLで記録する。見た目で気になった挙動を、あとからフレーム単位で確認できるようにする。

## 出力

| フィールド | 内容 |
| --- | --- |
| `frame` | フレーム番号 |
| `elapsed` | 経過秒 |
| `ghosts` | 各キャラクターの座標、速度、向き、行動、回転中か、会話テキスト、移動目標 |
| `objects` | 各配置オブジェクトのID、タグ、座標、表示状態、発光状態 |

## 起動

```powershell
.\.venv\Scripts\python.exe game.py --test-frames 600 --seed 12345 --evaluation-log tmp\evaluation\runtime.jsonl --evaluation-interval 10
```

自動評価では短い評価ログ生成も実行する。
