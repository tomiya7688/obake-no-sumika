# obakeno_sumika_special ver
ハイエンド版です。まるとかどかには言語モデルが搭載され(言語モデルは検討中です 1~3B程度のものを想定しています)知っていることと知らないことがjsonで記録されています。
情報はjsonキーと値をキーにするを使って検索を再帰的に繰り返してからその内容について知っているか　知識があるか　どういうものだと認識しているか　やったことがある　たべたことがある　などを算出して応答を返します。
口調なども確定しています
ただ、この版は明らかに重たいと思うので別版、かつorginal版とテスト環境が混在しないように気をつけてください
なので彼らとチャットすることが出来ます。
conversationの方もプリセットだけでなく、会話を生成というタスクを組めるようになります。
idオブジェクトとも連携できます。
またuserが送信した内容はjsonに書き込まれていきおばけたちの知識のアップデートに役立ちます
スマホという名前を聞いただけなら状態は '名前を聞いたことがある' になります
'知っている'になったばあいは'スマホについて知っている'の知っている内容について書かれたものがjsonにまた記録されています。
「知ってるのだ！」と言っていてもその中身によっては
スマホ　知ってる　硬い
ぐらいしか知らないこともあります。

これについて開発者用のjson編集ツールを同時に実装しながら実装する必要があります
